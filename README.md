# Bunkr

> Attendance tracking, kept simple. One page, in your browser, no install.

**Live:** https://theadwaithvarma.github.io/bunkr

## What it is

Bunkr is a small web app for tracking attendance. Everything lives in a single file, so there is no build step, no framework to install, and nothing to set up. Open it and it just works.

## Features

- Record attendance day by day
- Review your attendance history at a glance
- Runs entirely in the browser

## How it works

The whole app is one file:

```
index.html
```

Open that file and you are in. No server, no build, no dependencies.

## Run it locally

Serve the folder with a static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

Or just use the live link above.
